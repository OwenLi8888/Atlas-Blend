# Legacy audit

Written on 2026-11-15 from branch `feature/photo-picks` (cut from `main` at `73d5050`). Nothing
listed here was deleted, moved or edited. It is a list for one clean-up pass later.

How it was made: start at `index.html` → `src/main.tsx` → `src/App.tsx`, follow every import, and
check every file in `public/` and `scripts/` for a reference from that live tree, `package.json`
or the README.

- `origin/recs` adds `server/` (Express + Supabase + Typesense), `src/rec/scoring.ts` and
  `supabase/schema.sql`, and proxies `/api` to port 43871. The picks endpoint added here is
  `/api/picks`, which that server does not define.

  `worker/`, plus `design/`) and has no `src/` tree, so a merge with `main` will need care.
- `origin/restyle`, `origin/mosaic`, `origin/jakhangir/studio-home`, `origin/build/blend-v1` and
  `origin/globe-imaging-branch` are all already contained in `main`'s history. The last two are
  where the `api/`, `blend/` and globe code lived before it was removed from `main`.
